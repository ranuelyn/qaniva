## Full Code patterns deliberately not copied

- Side labels and controls surrounding all edges of the patient.
- Attending/nurse portrait chrome and game-like character framing.
- Dense, legacy-feeling action browsers and tiny text.
- Exact score categories, colors, language, icon arrangements or case artwork.

## Body Interact patterns deliberately not copied

- Predominantly white/teal shell and circular clinical toolbar styling.
- Exact orange/green priority cards, bottom icon order, scoring weights or feedback wording.
- Floating result cards that obscure the patient on a phone-sized viewport.

## Oxford patterns used only as direction

- Neutral, believable environment scale and equipment placement.
- Patient face/pose readable at a glance.
- Lighting that supports clinical observation rather than drama.
- Interaction affordances that are legible without making the room feel like a game HUD.
