## Rigged patient research (QAN-020, 2026-08-31)

Options evaluated before building first-party:

| Option | License / commercial use | Verdict |
| --- | --- | --- |
| Poly Pizza (Quaternius etc., CC0) via blender-mcp | CC0 — ideal | installed blender-mcp addon predates Poly Pizza support; manual download needs per-file license page verification — deferred |
| Mixamo characters | free with Adobe account; usable in products, no redistribution as rig | requires interactive Adobe login — not automatable here; viable manual route later |
| Unity Asset Store medical packs (e.g. ItHappy "Medical" pack: staff+patients, ~30 anims, Mixamo-compatible) | paid, standard Asset Store EULA (per-seat) | **RECOMMENDED PURCHASE** for production art: a professional patient + animation set (~$40–100 class) unlocks believable movement, sex/body variants, and clothing without art staff. Decide before beta. |
| Sketchfab/game rips/unclear licenses | — | prohibited |
| **First-party Blender generator (chosen)** | n/a — zero licensing surface, deterministic, ~250 KB | the safe temporary rig: stylized but coherent; bone+material names are the runtime animation contract |

## Rules for adding an external asset

Record here BEFORE import: name, source URL, license (must permit commercial
use), attribution requirement, file size, poly count (if mesh), and why a
generated placeholder is insufficient. No Sketchfab rips, no unclear licenses,
no multi-hundred-MB packs, textures ≤2K with mobile compression. Git LFS is not
initialised — adding binary art requires `git lfs install` first
(`.gitattributes` rules already exist).
